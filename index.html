Segurança adotada

Somente um usuário autenticado com role = admin e active = true pode executar as ações desta página.

Desativar é a opção recomendada quando um funcionário deixa de usar a aplicação: o acesso é bloqueado, mas o histórico de conferências permanece preservado. A exclusão definitiva só é permitida para usuários sem histórico no inventário.

Não existe uma segunda senha administrativa salva no HTML. A autorização é validada novamente no servidor a cada operação.
