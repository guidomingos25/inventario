Gerenciamento de usuários

Cadastre, edite, desative e exclua usuários sem acessar o painel de Authentication.

As operações administrativas são validadas novamente no servidor. Administradores de filial visualizam e gerenciam somente usuários pertencentes às suas filiais; administradores globais podem gerenciar todas.

Novo usuário

O usuário será criado já confirmado, pronto para entrar com e-mail e senha.

Com uma única filial, o usuário entra diretamente nela.

Segurança adotada

O acesso administrativo é validado por perfil e filial. Admin Global administra todas as filiais; Admin de Filial administra somente usuários e dados das filiais às quais está vinculado.

Desativar é a opção recomendada quando um funcionário deixa de usar a aplicação: o acesso é bloqueado, mas o histórico de conferências permanece preservado. A exclusão definitiva só é permitida para usuários sem histórico no inventário.

Não existe uma segunda senha administrativa salva no HTML. A autorização é validada novamente no servidor a cada operação.
